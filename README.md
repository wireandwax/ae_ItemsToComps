# All Items to Comps

An Adobe After Effects script that automatically creates a composition for each item in the Project panel, using the source item’s properties to configure the new composition.

Each composition inherits the source item’s dimensions, pixel aspect ratio, duration and frame rate, with the original item added as a layer. Designed to speed up repetitive composition setup and streamline motion graphics workflows.

## Features

- **Automatic composition creation** — Generate a new composition for each project item.
- **Property matching** — Inherit dimensions, pixel aspect ratio, duration and frame rate from the source.
- **Automatic layer placement** — Add each source item to its corresponding composition.
- **Undo support** — Group operations into a single undoable action.

## Notes

- Best used on carefully selected project items to avoid creating unwanted duplicate compositions.

## Built With

- Adobe After Effects
